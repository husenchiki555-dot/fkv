# Party Charades (offline Android)

Offline Android charades game with 50 built-in decks and 4,851 explicit charades cards. Includes multi-deck / stack mixing, tilt controls, custom timers up to 10:00, Easy/Normal/Hard/Mixed difficulty, age/theme filters, search, custom comma/newline-separated decks, same-phone team play, and local-network room-code scoring on the same Wi-Fi/hotspot.

## Content quality
The built-in pack now uses direct words, names, titles and natural charades actions instead of automatically padding every deck with phrases such as “talking about X”, “ordering X” or “recognizing X”. Deck sizes intentionally vary, usually around 80–100 cards, so quality is not sacrificed to hit an arbitrary count.

## Mixed decks
From the home screen, choose **Mix decks / stacks**, select any 2 or more built-in or custom decks, and play them as one shuffled deck. Duplicate card text is removed when decks overlap.

## Build notes
